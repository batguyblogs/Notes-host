## KNN / K Nearest Neighbour Algorithm
It is a widely used Machine Learning algorithm for classification and regression tasks.
It works by identifying the K closest data points to the given inputs and making prediction based on the majority class or average value of those neighbours.

Steps to implement KNN
1. Select the value of $K$ for prediction
2. Calculate Euclidian Distance from the stored dataset $\sqrt{ (x_{1}-x_{2})^{2} + (y_{1}-y_{2})^{2}}$
3. Find the K nearest neighbour, the smallest euclidian distance
4. Apply majority voting for classification (or) taking average for regression
